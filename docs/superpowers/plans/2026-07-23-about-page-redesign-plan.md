# About Page Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Redesign the About page with dynamic stats/credentials/FAQ content on `BusinessInfo`, and restyle + extend the site-wide nav header, matching the approved design spec.

**Architecture:** Add three JSON fields to the existing `BusinessInfo` model (one plain, two translated via `django-modeltranslation`), simplify `AboutPage`'s context to rely on the existing site-wide `business_info` context processor instead of a page-local re-query, rebuild `about.html` as five sections (hero → info → stats → credentials → FAQ) plus the untouched reviews/footer, and restyle/extend `templates/partials/header.html` + `header.css`.

**Tech Stack:** Django 5.x, `django-modeltranslation` 0.20.3, Django template language, plain CSS (existing custom-property theming system), Django `TestCase` + `Client`.

## Global Constraints

- Never hardcode hex colors in CSS/templates — use the existing `var(--primary-color)`, `var(--bg-light)`, `var(--text-main)`, `var(--text-muted)`, `var(--accent-color)`, `var(--font-heading)`, `var(--font-main)`, spacing (`--space-*`), radius (`--radius-*`), and shadow (`--shadow-*`) custom properties (see `staticfiles/css/base/variables.css` and `templates/partials/theme_overrides.html`).
- Follow existing naming/registration patterns: `django-modeltranslation` fields are registered in `massageProject/main_app/translation.py`; admin classes live in `massageProject/main_app/admin.py` and already use `TabbedTranslationAdmin`.
- Test files use the `tests_<topic>.py` naming convention inside `massageProject/main_app/` (see `tests_comments.py`, `tests_feature_flags.py`).
- After all template text changes are in, run `makemessages -l bg -l en`, fill in the new `msgid` entries in both `.po` files, then `compilemessages` (see final task).
- `stats` is a single shared (untranslated) JSON value; `credentials` and `faq` are translated JSON values (separate `_bg`/`_en` columns via modeltranslation).
- A stat card renders only if its specific JSON key has a value; the whole stats section renders only if at least one of the 4 keys is present. Credentials section renders only if `training` or `recognition` is non-empty (and each sub-list independently). FAQ section renders only if the list is non-empty.

```python
class AboutPage(TemplateView):
    template_name = 'pages/about.html'

    def get_context_data(self, **kwargs):
        context = super().get_context_data(**kwargs)
        context['comments'] = Comment.objects.filter(is_reviewed=True).order_by('-created_at')[:15]
        context['total_comments_count'] = Comment.objects.filter(is_reviewed=True).count()
        if 'form' not in context:
            context['form'] = CommentForm()

        user = self.request.user
        if user.is_authenticated and not (user.first_name and user.last_name) and 'name_form' not in context:
            context['name_form'] = UserNameForm()
        return context
```
